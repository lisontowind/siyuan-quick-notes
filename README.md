# 悬浮速记

想法来了，不必切回思源找文档。按 **Ctrl + Alt + N**，打开一张小便签，记下灵感、待办或临时摘录；停下输入后，内容自动保存到思源。

适用于 **Windows 桌面版思源 3.8.6 或更高版本**。使用时需要思源保持运行。

## 开始使用

1. 从 [GitHub Releases](https://github.com/lisontowind/siyuan-quick-notes/releases/latest) 下载并解压 `package.zip`，将内容放入 `<工作空间>/data/plugins/siyuan-quick-notes/`。更新已有版本时，请先备份原插件目录。集市上架后也可直接搜索“悬浮速记”安装。
2. 打开思源，在 **设置 → 集市 → 已下载 → 插件** 中启用“悬浮速记”。
3. 点击顶栏的 **悬浮速记 → 速记设置**，确认保存位置。

**第一次使用，先选择目标笔记本**。默认保存位置为 `/闪念速记/{{now | date "20060102150405"}}`，按首次输入的年月日时分秒生成文档路径，例如 `/闪念速记/20261010035000`。每条便签保存在自己的**竖向超级块**中，同一路径的便签追加到同一文档。

保存目录支持思源的模板变量，模板结果直接作为文档路径，不追加编号或子文档。例如 `/Quick Notes/{{now | date "2006-01-02"}}` 将当天的便签汇集到 `/Quick Notes/2026-10-10`；每条便签只编辑自己的超级块，保留文档中的其他内容。不含模板变量的普通目录（例如 `/Quick Notes`）仍在该目录下生成时间与编号文档名。时间格式使用 Go 的参考日期 `2006-01-02`，由思源内核解析。第一次输入时确定路径，之后重试或跨日编辑仍保存到原位置；修改设置只影响新便签。

设置中的 **预览保存位置** 会展示当前笔记本和解析后的完整路径，不创建文档。时间模板以预览时刻计算，实际新速记仍在首次输入时确定路径。保存设置前会校验笔记本、目录及模板，错误输入会明确提示，不会悄悄改成默认目录。

插件及其设置仅在 Windows 桌面端生效，不读取或修改原生闪念速记的默认配置。

## 记下一个想法

- **随时新建**：按 `Ctrl + Alt + N`，或点击速记窗口顶部的加号。可以同时打开多张便签。
- **直接写正文**：便签只有 Markdown 正文编辑区，不设单独的标题输入框；每条正文保存为竖向超级块，内容从上到下排列。
- **区分多个窗口**：左上角显示对应的思源文档标题，可拖动这一区域移动窗口。托盘列表和最近记录显示正文首个非空行。快捷键可以设为唤醒最近窗口，顶部加号始终新建。
- **放在手边**：点击图钉置顶，拖动顶部空白区域移动窗口，拖动边缘调整大小。
- **回到思源**：点击右上角箭头，打开对应的思源文档。
- **找回旧笔记**：打开“最近速记与恢复草稿”，按首行摘要、保存位置或时间搜索。点击记录即可继续编辑。
- **从托盘打开**：绿色便签图标左键新建，右键打开最近记录、窗口列表和设置。右键选择“关闭托盘图标”会保存关闭设置；可从思源顶栏的速记设置重新开启。

编辑器支持 Markdown 源码，适合文字、列表、代码块、表格和图片链接。截图后回到便签按 **Ctrl + V** 即可插入；也可通过 **更多 → 插入图片** 选择图片，或直接将图片文件拖入编辑区。悬浮窗口拖入时插在落点，选择与粘贴时插在当前光标或替换选区；降级窗口提供“插入图片”按钮，拖入时使用当前光标位置。

图片支持 PNG、JPEG、GIF、WebP 和 BMP，每次最多 10 张、总计不超过 20 MB。上传成功后插入 Markdown 图片链接，图片保存在思源工作空间的 `data/assets/`，随思源资源同步。悬浮便签会在链接下方直接显示图片，按窗口宽度缩放；点击“编辑图片链接”可选中对应源码。重新打开正式速记或恢复草稿时，也会显示已有图片。

预览只读取思源资源目录中的上述图片格式，代码块中的图片示例和外部图片地址不会自动加载。图片资源不存在或无法读取时，显示“图片无法加载”提示，正文和链接仍可编辑保存。其他 Markdown 内容仍显示源码，降级窗口仍使用源码编辑区；不支持其他附件。

上传期间正文暂时只读，普通关闭或重新载入会提示等待完成。失败时保留原正文，需重新粘贴或选择图片；尚未插入的图片不在本机恢复草稿中。部分上传失败、超时或中途停用插件可能留下未引用的思源资源，可用思源的资源管理功能处理；插件不自动删除资源。

| 操作 | 入口 |
| --- | --- |
| 新建速记 | `Ctrl + Alt + N` / 顶部加号 |
| 立即保存 | `Ctrl + S` / 更多 → 立即保存 |
| 插入截图或图片 | `Ctrl + V` / 更多 → 插入图片 / 拖入图片文件 |
| 置顶或取消置顶 | 顶部图钉 |
| 保留草稿后关闭 | 更多 → 保存本机草稿后关闭 |
| 另存一份 | 更多 → 另存为新速记 |
| 删除速记 | 右上角更多 → 删除这条速记 / 最近列表中的删除按钮 |
| 修改快捷键 | 思源快捷键设置中搜索“新建悬浮速记” |

## 内容保存在哪里？

停止输入 **800 毫秒**后自动保存；切换到其他窗口、按 `Ctrl + S` 或普通关闭时，也会提交保存。正文为空的便签不会创建文档。

**“已保存到思源”才表示正式保存成功。** 输入期间还会保存本机恢复草稿。普通关闭先确认草稿落盘，再保存到思源；思源保存失败时仍会关闭，并提示已保留本机草稿。只有最新草稿未确认落盘时，窗口才会保留。

目标**文档标题**显示在左上角，例如 `20261010035000`；下次保存或重新载入时读取当前标题，暂时无法读取时使用上次标题或保存路径末尾的文档名。编辑正文不会重命名文档。底部只显示保存状态或错误提示，不重复显示文档标题；关闭保存成功提示后，成功状态会隐藏。

旧版便签填写过的标题会作为正文开头的一级标题保留，正式文档和恢复草稿都能在正文中继续编辑或删除这段文字，不会自动重复添加。

旧版横向超级块的便签下次修改保存时会原位改为竖向布局，块 ID 和所在文档保留。0.1.17 保存成独立文档的便签下次修改保存时会复制为当前保存位置中的竖向超级块，原独立文档保留。升级本身不会批量迁移或删除思源内容。

只想暂时收起窗口时，选择 **更多 → 保存本机草稿后关闭**，之后从恢复列表继续。草稿只在当前电脑，不随思源同步到其他设备。

最近列表默认记忆 50 条正式保存记录，可在速记设置的“最近速记记忆条数”中调整为 1–200 条。调小后立即移出较旧的列表记录，不删除思源正文或本机恢复草稿；调大不能找回已移出的记录。恢复草稿独立保留，不占这个额度。新安装默认窗口宽度为 320 像素，可在设置中调整；已保存的窗口尺寸继续沿用。

默认最多同时打开 **10 个便签**，可在速记设置的“最多同时打开的便签”中调整为 **1–50 个**。新建、另存和窗口恢复均受此限制；达到上限时先关闭一个便签再打开，快捷键会唤醒最近窗口。调小上限保留已打开的便签。升级保留此前保存的上限设置。

删除速记前会在思源主窗口弹出确认框。确认后**只清理插件中的本机草稿、最近记录和窗口恢复记录**，并关闭对应便签；**思源文档及其中的全部内容保留**，不调用思源删除接口。尚未保存的本机内容会被删除，无法通过插件撤销。本机草稿清理失败时保留窗口和记录，可重试。

在设置中开启“重启后恢复上次打开的窗口”，下次加载插件时会恢复便签，包括尚未正式保存的草稿。默认关闭此选项，草稿恢复入口仍然保留。

打开窗口的笔记索引独立保存在本机，不受最近记录数量限制。恢复正式速记时读取思源中的最新正文；恢复草稿时保留本机尚未提交的内容。更新前已经移出最近列表且没有恢复草稿的旧窗口，无法凭旧版窗口尺寸记录找回。

窗口恢复优先使用最后记录的位置、尺寸与置顶状态；没有窗口记录时才使用草稿里的位置。个别记录无法打开时会继续尝试其余便签，直到达到窗口数量上限。反复恢复不会持续增大窗口尺寸。

## 遇到保存失败怎么办？

- **提示保存位置无效**：到速记设置选择一个已打开的普通笔记本，检查保存目录是否以 `/` 开头；模板出错时检查变量及时间格式。
- **提示原文已被修改**：先保留当前窗口内容。可“另存为新速记”保留一份，或确认后“重新载入原文”。插件会停止自动覆盖，避免把另一处的修改抹掉。
- **提示代码块或超级块未闭合**：补齐 Markdown 的结束标记，或先保存本机草稿。
- **提示与插件失去连接**：保持思源运行，检查插件是否启用；保留窗口文本再处理。
  失联超过 6 秒后，便签保留正文供选择和复制，并停止编辑。复制文本后点击关闭，按提示再次点击即可关闭窗口。暂时失联后通信恢复，会恢复编辑并重新提交未确认的输入。
- **提示草稿未落盘**：先复制正文到其他地方。此时不能把关闭窗口当作安全保存。

关闭或重新载入中断后，保留的窗口会恢复编辑，并按设置的防抖间隔继续尝试保存未提交的内容。外部修改冲突仍需手动处理。

重新载入前会先更新恢复草稿；更新失败时保留当前修改。若提示“本机草稿清理失败”，本机留下的是已载入的正文，可在文件占用解除后再次保存清理。设置只有在确认保存成功后才生效。窗口数量已满时，“另存为新速记”会提示先关闭一个窗口，再重试。

正常禁用插件会先收集窗口内容并确认草稿。强制结束思源、断电或磁盘故障仍可能丢失最后的输入，重要内容请留意保存状态。

更新或停用插件时，已确认本机草稿落盘的便签会关闭，可从“最近速记与恢复草稿”继续；开启窗口自动恢复时，重新加载插件会恢复便签。收集或落盘失败时保留正文供复制，关闭按钮会先提示复制，再次点击后关闭。

## 当前范围

支持多窗口、独立置顶、窗口位置记忆、托盘入口和本机草稿恢复。支持已打开的普通非加密笔记本；思源完全退出后不能独立速记。单条速记最多 200 万字符。

编辑正式速记可能重建内部子块；需要长期引用某个子块时，建议回到思源编辑。多设备同时改同一条速记时，请留意冲突提示。

详细的实机通过项目和待测项目见 [测试记录](docs/testing.md)。开发和构建说明见 [开发文档](docs/development.md)。
