# 悬浮速记

想法来了，不必切回思源找文档。按 **Ctrl + Alt + N**（macOS：**Option + Command + N**），打开一张小便签，记下灵感、待办或临时摘录；内容默认自动保存在本设备的插件草稿中；手动保存到思源成功后，后续修改自动同步。也可在设置中开启“默认保存到思源”，直接自动保存到思源。

适用于 **Windows、macOS、Linux 桌面版思源 3.8.6 或更高版本**。使用时需要思源保持运行。macOS/Linux 的实机验收状态见 [测试记录](docs/testing.md)。

悬浮便签和独立最近列表随思源界面语言显示中文或英文，覆盖内置设置、工具栏、更多菜单、编辑器、图片预览和保存状态；修改思源语言后请重新加载插件。托盘及降级面板目前仍使用中文，英文使用说明提供对应菜单对照。

## 功能一览

格式工具栏使用统一的 Lucide 图标。点击标题可选择正文或 H1–H6；拖动按钮调整顺序，右侧“更多格式”按窗口宽度收纳溢出的按钮，并提供完整排序面板、键盘调整和恢复默认顺序。顺序会保存并随思源同步到其他设备。

便签列表显示本设备草稿和共享的已保存记录。右上角 **更多 → 其他设备草稿** 入口可只读预览已同步的外机草稿，点击 **复制到本设备** 后生成独立便签继续编辑。需要各设备使用同一个同步空间，并且没有排除 `storage/petal/siyuan-quick-notes/drafts/`、`shared/`、`settings.json` 或 `toolbar.json`。工具栏顺序、插件设置、思源正文和图片仍沿用工作空间同步。

从列表删除时在列表内确认，删除状态同步到其他设备，思源正文保留。其他设备的未保存修改不会被远程清除：已打开的便签停止自动保存，保留复制或另存入口；尚未被确认清理的草稿版本显示“已移除 · 草稿恢复”。未保存草稿按设备独立保存，外机草稿只读查看；窗口位置、实际尺寸、置顶和打开状态仍按设备隔离，其他设备不会自动打开你的便签。默认窗口尺寸等功能设置继续同步。

| 想做什么 | 悬浮速记怎么帮你 |
| --- | --- |
| 随手捕捉灵感 | 全局快捷键唤起独立便签，支持多窗口、置顶与位置记忆 |
| 记录文字和图片 | 默认 Markdown 即时渲染，可切换源码；截图粘贴、图片选择和拖入；思源资源图片直接预览 |
| 按需保存到思源 | 可开启“默认保存到思源”；默认先保存在插件中，手动保存到思源后自动同步。停笔 800 毫秒保存，每条便签独立保存为原生提示块 |
| 继续未完成的记录 | 搜索最近速记，恢复本机草稿，按需恢复上次打开的窗口 |

## 开始使用

1. 从 [GitHub Releases](https://github.com/lisontowind/siyuan-quick-notes/releases/latest) 下载并解压 `package.zip`，将内容放入 `<工作空间>/data/plugins/siyuan-quick-notes/`。更新已有版本时，请先备份原插件目录。集市上架后也可直接搜索“悬浮速记”安装。
2. 打开思源，在 **设置 → 集市 → 已下载 → 插件** 中启用“悬浮速记”。
3. 点击顶栏的 **悬浮速记 → 速记设置**，在列表窗口的 **设置** 页确认保存位置。

![保存位置图解：选择目标笔记本，填写目录模板，预览解析后的文档路径](https://raw.githubusercontent.com/lisontowind/siyuan-quick-notes/5b694913c9b46b4f5032035c49879cf2c0c39048/docs/images/03-storage.png)

*设置图来自本版内置设置，展示按天汇集的示例模板；首次安装默认使用下面的时间戳模板。*

**首次保存到思源前，选择目标笔记本**；仅保存在插件中无需配置笔记本。默认保存位置为 `/闪念速记/{{now | date "20060102150405"}}`，按首次保存到思源时的年月日时分秒生成文档路径，例如 `/闪念速记/20261010035000`。每条便签保存在自己的**原生提示块**中，同一路径的便签追加到同一文档。

保存目录支持思源的模板变量，模板结果直接作为文档路径，不追加编号或子文档。例如 `/Quick Notes/{{now | date "2006-01-02"}}` 将当天的便签汇集到 `/Quick Notes/2026-10-10`；每条便签只编辑自己的提示块，保留文档中的其他内容。不含模板变量的普通目录（例如 `/Quick Notes`）仍在该目录下生成时间与编号文档名。时间格式使用 Go 的参考日期 `2006-01-02`，由思源内核解析。首次保存到思源时确定路径，之后重试或跨日编辑仍保存到原位置；修改设置只影响尚未确定位置的便签。

设置中的 **预览保存位置** 会展示当前笔记本和解析后的完整路径，不创建文档。时间模板以预览时刻计算，实际速记在首次保存到思源时确定路径，已有保存位置继续沿用。保存设置前会校验笔记本、目录及模板，错误输入会明确提示，不会悄悄改成默认目录。

点击速记列表右上角的 **设置齿轮** 打开内置设置，左上角的返回按钮回到列表。保存位置、快捷键行为、托盘、窗口尺寸与置顶、自动保存和历史条数均可调整，点击 **保存设置** 后生效；保存失败时保留输入。返回列表会保留未保存的设置、列表搜索词与滚动位置。**重新载入设置** 会丢弃尚未保存的设置输入，读取当前生效配置。顶栏、托盘及思源插件的设置入口也直接打开内置设置；原生窗口不可用时使用原来的主界面设置面板。修改全局快捷键仍通过思源快捷键设置完成，打开该入口时会最小化列表窗口。

**快捷键行为** 可选择“新建速记”“唤醒最近窗口”或“打开速记列表”，默认仍为新建。选择打开列表后，即使便签数量已满也能唤起列表；右下角加号始终新建便签，托盘左键行为独立设置。

插件及其设置仅在 Windows、macOS、Linux 桌面端生效，不读取或修改原生闪念速记的默认配置。

## 记下一个想法

![便签操作图解：顶部编辑标题与置顶，正文即时渲染，底栏提供格式、新建与思源保存](https://raw.githubusercontent.com/lisontowind/siyuan-quick-notes/5b694913c9b46b4f5032035c49879cf2c0c39048/docs/images/01-window.png)

*便签图由当前版本界面代码渲染，正文为演示数据。顶部保留标题编辑、置顶、更多、最小化和关闭；新建与思源保存/打开位于右下角。*

- **随时新建**：按 `Ctrl + Alt + N`（macOS：`Option + Command + N`），或点击速记窗口右下角的加号。可以同时打开多张便签。
- **直接写正文**：便签只有 Markdown 正文编辑区，不设单独的标题输入框；保存到思源时，每条正文保存为原生提示块，内容从上到下排列。
- **区分多个窗口**：左上角显示对应的思源文档标题，可拖动这一区域移动窗口。单击标题旁的铅笔按钮可设置自定义便签标题；托盘列表和最近记录优先显示该标题，否则显示正文首个非空行。快捷键可以设为唤醒最近窗口，右下角加号始终新建。
- **放在手边**：点击图钉置顶，拖动顶部空白区域移动窗口，拖动边缘调整大小。
- **保存或回到思源**：右下角箭头在首次保存前显示“保存到思源中”，点击只保存；成功后切换为“在思源中打开”。列表每条记录右侧也提供同样的按钮，位于删除按钮上方。
- **找回旧笔记**：打开独立的“速记列表”窗口，按首行摘要、保存位置或时间搜索。点击记录继续编辑，列表保持打开；列表本身也可以置顶。
- **从托盘打开**：Windows 的绿色便签图标、macOS 的单色菜单栏图标默认左键新建、右键打开菜单；可在设置的“托盘左键行为”中改为打开最近列表，保存后立即生效。此选项独立于全局快捷键行为。Linux 使用桌面环境提供的托盘菜单。选择“关闭托盘图标”会保存关闭设置；可从思源顶栏的速记设置重新开启。

### Markdown 即时渲染

便签默认开启即时渲染，可直接编辑正文。已识别的标题、粗体、斜体、下划线、删除线、行内代码、引用、列表等语法标记始终隐藏，点击、移动光标或选择文字不会展开源码。待办框可直接切换，支持撤销；表格保持渲染展示，修改表格及图片、链接地址时使用底栏的源码按钮。

底栏右侧的 **显示源码 / 返回渲染** 按钮切换整个编辑器的显示方式，保留正文、选区及撤销历史，不触发保存；源码模式暂停排版和图片预览。另一个 **显示工具栏 / 隐藏工具栏** 按钮展开底栏上方的格式操作，默认收起，窄窗口内自动收纳到“更多格式”。工具包含加粗、斜体、下划线、删除线、正文及 H1–H6 标题、列表、待办、引用、行内代码、链接与图片，两种模式都能使用。先选择文字再点击可应用或取消对应格式；空选区插入标记并将光标放在中间。链接工具会先要求填写 HTTP/HTTPS 地址。

下划线以思源支持的 `<u>文字</u>` 保存；只渲染无属性、成对的下划线标记，不执行任意 HTML。其他 HTML、思源特殊语法和未支持内容保留原文；超大表格保留源码以避免界面卡顿。本次不渲染公式或图表，降级编辑器继续使用源码。源码与工具栏显隐仅作用于当前窗口，重新打开默认渲染、工具栏收起。

### 插入截图和图片

![图片插入图解：粘贴截图、选择文件或拖入图片，保留 Markdown 链接并在下方直接预览](https://raw.githubusercontent.com/lisontowind/siyuan-quick-notes/5b694913c9b46b4f5032035c49879cf2c0c39048/docs/images/02-images.png)

*配图来自本版即时渲染界面，使用插件图标作为示例图片；底栏可切换源码编辑图片链接。*

编辑器以 Markdown 保存正文，默认即时渲染。截图后回到便签按 **Ctrl + V**（macOS：**Command + V**）即可插入；也可通过 **更多 → 插入图片** 选择图片，或直接将图片文件拖入编辑区。悬浮窗口拖入时插在落点，选择与粘贴时插在当前光标或替换选区；降级窗口提供“插入图片”按钮，拖入时使用当前光标位置。

图片支持 PNG、JPEG、GIF、WebP 和 BMP，每次最多 10 张、总计不超过 20 MB。上传成功后插入 Markdown 图片链接，图片保存在思源工作空间的 `data/assets/`，随思源资源同步。渲染模式隐藏已支持的图片链接并显示按窗口宽度缩放的预览；底栏切换源码后可编辑原链接。重新打开正式速记或恢复草稿时，也会显示已有图片。

预览只读取思源资源目录中的上述图片格式，代码块中的图片示例和外部图片地址不会自动加载。图片资源不存在或无法读取时，显示“图片无法加载”提示，正文和链接仍可编辑保存。降级窗口仍使用源码编辑区；不支持其他附件。

上传期间正文暂时只读，普通关闭或重新载入会提示等待完成。失败时保留原正文，需重新粘贴或选择图片；尚未插入的图片不在本机恢复草稿中。部分上传失败、超时或中途停用插件可能留下未引用的思源资源，可用思源的资源管理功能处理；插件不自动删除资源。

## 找回最近速记与草稿

![恢复图解：搜索摘要、保存位置或时间，点击正式记录继续编辑，恢复本机草稿或上次打开的窗口](https://raw.githubusercontent.com/lisontowind/siyuan-quick-notes/5b694913c9b46b4f5032035c49879cf2c0c39048/docs/images/04-recovery.png)

*列表图来自本版独立窗口，记录内容与时间为演示数据。*

从 **便签更多菜单、思源顶栏或托盘菜单** 打开独立的“速记列表”窗口。重复打开会唤醒已有列表；列表不占便签数量额度，打开条目后仍然保留。列表合并已打开便签、本设备草稿和最近记录，按便签去重、按更新时间倒序排列，显示草稿和已打开标记。按首行摘要、保存位置或时间搜索，刷新时保留搜索词和滚动位置。

点击记录时优先唤醒已打开的便签，其次恢复本机草稿，否则读取思源最新正文。列表默认 400×560、不置顶，可独立置顶和最小化；启用“记忆窗口位置、大小与置顶”时保存列表自己的状态，重启时不自动打开列表。窗口状态保存在当前设备草稿目录中的 `recent-window.json`。原生窗口不可用时使用主界面恢复弹窗。

想暂时收起便签时，选择 **更多 → 保存草稿后关闭**。草稿在本设备列表继续；其他设备可查看并复制后编辑。设置中的 **重启后恢复上次打开的窗口** 默认关闭，可按需开启；关闭自动恢复时，仍能手动找回草稿。

**删除清理本机插件记录，并同步移除其他设备的列表记录，思源文档及其内容保留。** 确认前请检查是否还需要未保存的草稿，具体保存与删除规则见下文。

## 整理便签、归档与清除

### 分设备草稿与外机查看

![外机草稿图解：只读预览已同步的完整正文，复制到本设备后继续编辑](https://raw.githubusercontent.com/lisontowind/siyuan-quick-notes/5b694913c9b46b4f5032035c49879cf2c0c39048/docs/images/06-devices.png)

草稿正文按设备保存在 `storage/petal/siyuan-quick-notes/drafts/<设备标识>/`。本设备速记列表、自动恢复及整理统计只读取本机草稿；已保存到思源的记录继续共享。等待思源同步完成后，点击列表右上角 **更多 → 其他设备草稿**，可查看设备标识、摘要、最后修改时间与完整只读正文。

外机草稿不能直接编辑、保存到思源或删除。点击 **复制到本设备** 会先在本设备落盘一条新便签，再打开编辑；副本使用全新标识，不继承原文保存位置、思源关联、同步基线或窗口状态。后续编辑与保存均独立于来源草稿。若来源已变化或消失，刷新后重试。查看范围仅包含已同步到当前工作空间的内容，离线未同步的最新输入不可见。

此前版本写入 `shared/drafts/` 的正文仍保留，无法由设备目录覆盖的旧版本以 **历史共享草稿** 提供只读恢复和复制入口。升级不自动合并、迁移或删除这些正文。删除记录后保留的本机修改也只能复制为新便签恢复。

速记列表底部状态栏显示全部未归档条数、未保存到思源的条数和可归档条数；**整理便签** 与 **其他设备草稿** 收纳在右上角的 **更多（⋯）** 菜单中。未达到阈值时不显示整理提醒或延期按钮；达到阈值且未延期时，底栏可选择 **7 天后再提醒**。整理页读取完整共享索引、本机草稿和正文副本，不受最近列表展示条数限制。

默认累计 **100 条**时，每台设备每天最多轻提示一次，可在列表选择 **7 天后再提醒**。设置中的 **启用整理提醒、整理提醒条数、归档候选天数** 可调整这些行为；默认选择最后修改超过 **30 天**的便签，已打开或正在处理的条目跳过。仅重新打开、载入相同正文不会刷新修改时间。提醒不会自动删除内容。

![整理图解：核对完整记录，选择归档或清除，确认未保存内容的处理](https://raw.githubusercontent.com/lisontowind/siyuan-quick-notes/5b694913c9b46b4f5032035c49879cf2c0c39048/docs/images/05-cleanup.png)

- **归档并移出插件**：先将未保存或待同步的最新内容写入思源，已有保存位置继续沿用；已同步的便签只核实原文可读取，不覆盖思源中的后续修改。逐条成功后清理插件正文副本、草稿和窗口记录，并同步移出其他设备的列表。之后请在思源查找，插件不再提供该条的副本恢复。
- **直接从插件清除**：不先保存，默认不勾选有未保存内容的条目。主动勾选后，确认框会明确显示将永久丢弃本机未保存内容的条数。思源文档和图片始终保留。

整理过程显示成功、失败和跳过数量，可重试失败项；停止操作只停止后续条目。保存失败、冲突、原文缺失或内容发生变化时保留该条。清理中断后保留可重试记录，重启继续清理已批准且内容未变化的条目。其他设备尚未提交的修改仍保留本机恢复入口；同步移除后，无待提交修改的本机副本会清理。离线设备同步回来的旧列表记录不会重新出现。

## 内容保存在哪里？

**默认保存到思源**：在设置的“保存与历史”中开启，先确认目标笔记本和保存目录。开启后，当前打开、新建或重新打开的非空草稿会在自动保存间隔后写入思源（默认 800 毫秒）；编辑、立即保存和正常关闭也使用此选项。空白便签不创建文档，只有标题的便签也可保存；失败时保留本机草稿。关闭开关后，尚未保存到思源的便签恢复为插件草稿，已保存便签继续自动保存后续修改。关闭状态的旧草稿在重新打开后才自动保存。

正文保存到思源后，随思源数据同步传到其他设备；需要各设备连接同一个同步空间，并等待同步完成。本选项只控制写入思源，不负责配置或触发云端同步。

未开启“默认保存到思源”时，新速记保存在本设备的插件草稿中。输入、按 `Ctrl + S`（macOS：`Command + S`）、立即保存或普通关闭均不会首次写入思源；非空便签关闭和重启后可从列表恢复；尚未保存到思源的便签若在关闭时为空白（包括仅有空格或换行），则自动删除插件记录。点击“保存到思源中”成功后，后续修改在停止输入 **800 毫秒**后自动同步到思源，立即保存和普通关闭也会提交同步。标题和正文均为空时不能首次保存到思源。

**“已保存到插件”表示当前设备的插件数据已落盘；“已保存到思源”才表示思源正文保存成功。** 首次手动保存仅写入思源，不自动打开文档；保存失败时保留插件正文和保存入口。已保存到思源的速记普通关闭时先确认草稿落盘，再同步思源；同步失败时仍会关闭并保留本机草稿。最新草稿未确认落盘时，窗口会保留。

插件会在当前设备的 `drafts/<设备标识>/saved/` 中保留已保存正文的完整副本。再次打开便签或点击“在思源中打开”时，若检测到思源原文已删除，会提示选择**恢复到思源、删除便签或取消**。恢复使用完整插件副本重新写入；删除清理插件记录、恢复草稿和副本。网络或内核请求失败不会被当作删除。旧版已经删除原文且没有完整副本的记录无法凭摘要恢复，可尝试思源历史或回收站。

左上角默认显示思源文档名（例如 `20261010035000`），可拖动移动窗口。**单击左上角标题旁的铅笔按钮** 可设置不超过 **200 字符**的单行便签标题，留空恢复默认显示。标题文字区域保留原生拖动和右键系统菜单；也可在便签内按 `F2`，或从右上角更多菜单选择“修改标题”。列表分行显示标题和正文摘要，没有标题时显示文档名或“未命名便签”。修改后自动落盘，关闭、重启、复制或另存后仍保留，并优先用于列表与托盘显示。已保存便签的标题随共享记录同步；未保存草稿仍按设备保存，外机复制会带上标题。

便签标题保存为提示块顶部标题，正文保存在块内，思源文档名保持不变。取消编辑不会保存；只有标题的便签也能保存到思源。底部继续显示保存状态或错误提示。

旧版便签填写过的标题会作为正文开头的一级标题保留，正式文档和恢复草稿都能在正文中继续编辑或删除这段文字，不会自动重复添加。

右下角的 **提示块类别** 按钮可选择 **NOTE（默认）、TIP、IMPORTANT、WARNING、CAUTION**。类别切换后便签背景立即变色，深色主题也有对应配色；正文保持原样，类别与标题一同自动保存，重启恢复和复制便签时都会保留。已保存便签会继续同步到原提示块。思源端更改了提示块标题或类别时，插件会检查冲突；重新载入可读回这些修改。

旧版横向或竖向超级块的便签下次修改或显式保存时会原位改为提示块，块 ID 和所在文档保留。0.1.17 保存成独立文档的便签下次修改保存时会复制为当前保存位置中的原生提示块，原独立文档保留。升级本身不会批量迁移或删除思源内容。

只想暂时收起窗口时，选择 **更多 → 保存草稿后关闭**，之后从本设备列表继续。草稿正文、恢复副本及窗口状态位于 `<工作空间>/data/storage/petal/siyuan-quick-notes/drafts/<设备标识>/`。其他设备只读查看这个目录中同步完成的草稿，需要复制到本设备后编辑；不会自动打开窗口或套用来源位置。

设备标识保存在当前系统用户主目录的 `.siyuan/quick-notes-device-id`，独立于工作空间；请保留该文件，以便重启后继续找到本机草稿。不要将它复制到另一台电脑。从 0.1.25 起，Windows 首次加载会复制并校验当前工作空间原先位于 `%LOCALAPPDATA%/SiYuanQuickNotes/` 下的草稿与窗口状态，原文件保留作为备份；迁移只执行一次，避免删除或正式保存后旧草稿再次出现。迁移失败时会停止初始化，保留旧文件供排查后重试。macOS/Linux 使用相同的设备隔离目录，不读取 Windows 旧目录。

最近列表默认显示 50 条正式保存记录，可在速记设置的“最近记录展示条数”中调整为 1–200 条。调小只减少展示数量，共享索引、思源正文和本机恢复草稿保留；调大后可以重新显示共享索引中保留的较旧记录。旧版升级前已经裁剪的记录不能凭空恢复。恢复草稿独立保留，不占这个额度。新安装默认窗口宽度为 320 像素，可在设置中调整；已保存的窗口尺寸继续沿用。

默认最多同时打开 **10 个便签**，可在速记设置的“最多同时打开的便签”中调整为 **1–50 个**。新建、另存和窗口恢复均受此限制；达到上限时先关闭一个便签再打开，快捷键会唤醒最近窗口。调小上限保留已打开的便签。升级保留此前保存的上限设置。

在列表删除速记时，确认框直接显示在列表面板内。确认后清理本机草稿、最近记录和窗口恢复记录，并关闭本机对应便签；删除标记同步移除其他设备的列表记录。**思源文档及其中的全部内容保留**，不调用思源删除接口。尚未保存的本机内容会被删除，无法通过插件撤销。其他设备的未保存内容保留供恢复或另存；本机草稿清理失败时保留窗口供重试，已经写入的共享删除标记仍然有效。便签自身“更多”菜单的删除入口继续使用思源确认框。

在设置中开启“重启后恢复上次打开的窗口”，下次加载插件时会恢复便签，包括尚未正式保存的草稿。默认关闭此选项，草稿恢复入口仍然保留。

打开窗口的笔记索引按设备独立保存，不受最近记录数量限制。恢复正式速记时读取思源中的最新正文；恢复草稿时保留本机尚未提交的内容。更新前已经移出最近列表且没有恢复草稿的旧窗口，无法凭旧版窗口尺寸记录找回。

窗口恢复优先使用最后记录的位置、尺寸与置顶状态；没有窗口记录时才使用草稿里的位置。个别记录无法打开时会继续尝试其余便签，直到达到窗口数量上限。反复恢复不会持续增大窗口尺寸。

## 遇到保存失败怎么办？

- **提示保存位置无效**：到速记设置选择一个已打开的普通笔记本，检查保存目录是否以 `/` 开头；模板出错时检查变量及时间格式。
- **提示原文已被修改**：先保留当前窗口内容。可“另存为新速记”保留一份，或确认后“重新载入原文”。插件会停止自动覆盖，避免把另一处的修改抹掉。
- **提示代码块或超级块未闭合**：补齐 Markdown 的结束标记，或先保存本机草稿。
- **提示与插件失去连接**：保持思源运行，检查插件是否启用；保留窗口文本再处理。
  失联超过 6 秒后，便签保留正文供选择和复制，并停止编辑。复制文本后点击关闭，按提示再次点击即可关闭窗口。暂时失联后通信恢复，会恢复编辑并重新提交未确认的输入。
- **提示草稿未落盘**：先复制正文到其他地方。此时不能把关闭窗口当作安全保存。

关闭或重新载入中断后，保留的窗口会恢复编辑，并按设置的防抖间隔继续尝试保存未提交的内容。外部修改冲突仍需手动处理。

重新载入前会先更新恢复草稿；更新失败时保留当前修改。若提示“本机草稿清理失败”，本机留下的是已载入的正文，可在文件占用解除后再次保存清理。设置只有在确认保存成功后才生效。窗口数量已满时，“另存为新速记”会提示先关闭一个窗口，再重试。

正常禁用插件会先收集窗口内容并确认草稿。强制结束思源、断电或磁盘故障仍可能丢失最后的输入，重要内容请留意保存状态。

更新或停用插件时，已确认本机草稿落盘的便签会关闭，可从“速记列表”继续；开启窗口自动恢复时，重新加载插件会恢复便签。收集或落盘失败时保留正文供复制，关闭按钮会先提示复制，再次点击后关闭。

## 当前范围

支持多窗口、独立置顶、窗口位置记忆、托盘入口和本机草稿恢复。支持已打开的普通非加密笔记本；思源完全退出后不能独立速记。单条速记最多 200 万字符。

Linux 的托盘显示与菜单交互取决于桌面环境；没有托盘时，可从思源顶栏新建或找回便签。X11 下沿用标准窗口和快捷键接口；Wayland 下全局快捷键、精确位置恢复、置顶与主动聚焦受思源宿主、桌面环境和权限限制，按系统能力尽力支持。窗口位置可能由系统重新安排，点击唤醒后也可能需要从系统窗口列表切换。插件不修改宿主启动参数或系统快捷键配置。[Electron 窗口说明](https://www.electronjs.org/docs/latest/api/browser-window)、[全局快捷键说明](https://www.electronjs.org/docs/latest/api/global-shortcut)

托盘不可用不影响顶栏入口；原生便签窗口无法创建时，提供明确标记的降级编辑器，可保存并打开思源官方文档窗口。说明图展示 Windows 风格操作，macOS 按上表使用 Command 快捷键。

编辑正式速记可能重建内部子块；需要长期引用某个子块时，建议回到思源编辑。多设备同时改同一条速记时，请留意冲突提示。

详细的实机通过项目和待测项目见 [测试记录](docs/testing.md)。开发和构建说明见 [开发文档](docs/development.md)。
