# 开发与构建

## 原生提示块保存与类别

`NoteRecord.calloutType` 默认为 `NOTE`，支持 `TIP/IMPORTANT/WARNING/CAUTION`；窗口编辑与关闭收集协议、共享摘要、设备草稿、副本、恢复和复制均携带类别。浮窗右下角使用可键盘操作的菜单，切换时只修改类别并按同一修订落盘，通过 `data-note-kind` 选择深浅色背景。降级面板复用相同类别与保存服务。

`wrapMarkdown` 保存为 `> [!TYPE] 图标 标题` 原生提示块，正文逐行增加一层引述，块级 IAL 保存稳定 ID 和插件身份。标题转义 Markdown 符号，并标记是否存在自定义标题，兼容解析器省略默认标题的情况。`unwrapNoteMarkdown` 去掉恰好一层外部提示块，清理内核生成的内部 IAL，保留代码与嵌套结构。标准格式依据 [思源原生提示块实现](https://github.com/siyuan-note/siyuan/issues/16051)，并以本机 Lute 验证。

保存与写后核对比较正文、类别与标题，外部任一项变化均触发既有冲突保护。旧 row/col 容器仅在写入或显式保存时原位转换，保留块 ID 与所在文档，升级与只读归档检查不批量改写。旧整篇文档记录沿用保留原文的迁移规则。正常清除仍不删除思源正文和资源。

## 自定义便签标题

新字段 `caption` 用于便签及原生提示块标题，与兼容旧版一级标题的 `title`、内核文档名 `docTitle` 分开。通过现有 `edit/collected` 版本协议与正文一起落盘，更新实际修改时间；窗口状态、索引、备份、重载与复制均保留该字段，清空后显示默认文档名。`noteLabel` 优先使用自定义标签；标题写入提示块顶部，思源文档名不变。只有标题的本机草稿不会被当成空白便签清除。

标题旁的铅笔是独立的 `no-drag` 按钮，单击直接打开标题输入框；标题文字保留 CSS 原生拖动和右键系统菜单。已移除不可靠的双击原生消息监听及窗口转发，F2 和更多菜单的“修改标题”保留为独立入口。降级面板同样提供铅笔按钮。编辑器处理单行与 200 字符校验、IME、取消、断连与关闭收集，标题草稿沿用现有磁盘错误和冲突保护。

## 分设备草稿与只读查看

`LocalDraftStore.write/list` 仅操作当前 `drafts/<device>/` 目录，普通列表、恢复和整理服务沿用这份本机数据。`listOtherDevices` 只读扫描已同步的其他设备目录，保留相同便签 ID 在不同设备的独立正文，返回稳定的来源键与设备 ID，不返回窗口几何状态。已确认保存且没有待提交修改的检查点不作为草稿展示。

`SharedDraftStore.listVersions` 仅用于兼容旧 `shared/drafts/` 因果版本。被对应设备文件覆盖的版本不重复展示，其余正文以历史共享草稿提供只读恢复。运行时不再发布、导入、合并或清理这些旧共享正文，已损坏的来源保留；本机落盘不依赖旧共享数据可读。

`draft-versions` 不带便签 ID 时读取外机目录；带 ID 时仅允许已移除的本机恢复草稿。`choose-draft-version` 只接受 `copy: true`，验证会话、预览令牌与来源快照后创建全新本机便签，清除原思源位置、基线、同步上下文和几何状态。先持久化再打开，打开失败可凭原令牌重试，不重复创建。原生列表与降级面板共用只读组件与宿主处理；没有继续编辑原始版本的接口。

## 便签整理与容量提醒

`CleanupService` 合并完整共享索引、设备草稿、saved/ 正文副本与活动窗口，按 ID 去重；最近列表的展示限制不影响统计和整理。宿主保存不透明预览版本，批量消息只传选中的 ID、版本、操作及明确的丢弃确认。执行前重新读取并比较版本，逐条锁定，拒绝重复任务并跳过已打开、忙碌或内容变化的条目。窗口打开、保存与删除入口共用该锁；任务启动立即确认，预览返回进度，心跳及停止后续处理不等待整批完成。

归档复用 `AutoSaveService` 的首次保存、冲突检查与写后核对；无待提交修改时仅通过 `NoteRepository.reload` 验证原文可读，不覆盖思源的新编辑。清理前原子写入设备目录的 `cleanup.json`，再写共享移除标记并清理准确匹配的草稿、副本和窗口状态。清理中断可重试，重启时只清理仍匹配批准版本的内容。远端移除仅清理无待提交修改的本机记录，保留本机修改用于恢复。共享摘要可回收，移除标记永久保留以防离线记录复活；索引读取允许摘要在并发回收时消失。

`reminder.json` 按设备和工作空间持久化每天提醒日期及延后截止时间。默认阈值 100、候选年龄 30 天，可关闭或调整。最近使用的悬浮便签展示带整理及延后按钮的轻提示，无悬浮窗口时使用宿主提示。列表和降级面板复用 `CleanupPanel`；保存设置时不要求纯本机用户先选择笔记本，但首次写入思源仍校验保存位置。仅实际内容变化更新编辑时间，原文读取使用现有副本作为比较基线。

## 思源原文删除与正文副本

确认保存或重新载入时，将完整正文原子写入设备草稿目录的 saved/ 子目录；清理恢复草稿不会清除此副本，用户删除便签才清理副本。打开已保存便签前刷新事务并检查内容块，只有成功查询后缺少内容块才产生 MissingSourceError；网络、内核及标识不匹配错误不进入删除提示。列表和便签入口在父窗口上显示恢复、删除、取消三项选择，降级环境使用主窗口对话框。恢复前再次检查原文；确实缺少时按原目标创建或追加内容，继续使用原便签和内容块标识，恢复后更新插件副本及共享引用。旧记录缺少完整正文时明确报错，不从摘要生成正文。

## 插件内保存与按需写入思源

新建记录带 `siyuanSaved: false`；仅在正文写入与核对成功后置为 true。旧记录缺少标记时按已有 docId 兼容识别。`flush()` 对未关联速记仅写入设备草稿，`saveToSiYuan()` 显式写入；已确认速记继续自动同步。输入期间保留插件内记录；尚未关联思源的空白新便签在收集最新正文后，关闭时自动删除草稿和窗口恢复记录。已关联思源的空白正文仍保留。只有确认同步成功的恢复草稿可清理。首次显式保存解析目标位置，输入不调用模板或笔记本接口。

窗口状态与 RecentItem 携带确认状态；列表的 `siyuan` 请求独立于打开插件编辑器的 `open` 请求。已打开便签先收集最新输入并确认本机落盘，关闭的便签使用临时服务直接保存，首次保存不打开思源。保存期间阻止重复操作，失败保留正文及保存入口。草稿与窗口恢复状态按设备隔离，外机草稿通过只读入口查看并复制。

## 工具栏与共享速记索引

`shared/notes/<便签 UUID>.<设备 UUID>.json` 保存每设备写入的已保存速记引用与摘要，不包含正文、baseline 或窗口几何。读取合并按更新时间排序，同一时间按文件名稳定取值；摘要只用于列表，打开时读取思源正文。`shared/deleted/<便签 UUID>.json` 为持久删除标记，始终优先于索引及旧历史迁移；不因显示数量限制或过期自动清除。设备各自的迁移标记位于 `shared/migrated/`，旧 history.json 保留且不再作为活动索引写入。

共享文件沿用本机 fsync、临时文件和原子替换。删除标记写入失败会阻止本机删除继续执行。索引损坏或正文尚未同步可用时报告错误，不凭摘要重建便签。`onDataChanged` 重新读取配置及共享索引，不在处理回调时写回；列表刷新和聚焦也重新读取共享记录。远程删除暂停对应保存服务并阻止后续显式保存及重新载入，未完成草稿保留供恢复或另存。已开始的内核写入无法跨设备撤销；仍依赖思源处理文档同步冲突。

工具栏顺序独立保存到 toolbar.json，与 settings.json 的表单写入分开。沙箱窗口以 save-toolbar 请求提交完整动作排列，宿主验证并确认写入后广播，失败回退到原布局。格式工具栏按实际宽度保留“更多”，排序既支持指针拖动，也支持完整面板中的移动按钮和 Alt+上下键。标题使用独立的 setHeading(0…6)，0 表示正文。图标为 Lucide 0.468.0 的本地 SVG 子集，可用 scripts/update-icons.mjs 从官方源或 lucide-static 对应版本 tar 包重新生成，构建不联网。

功能设置跟随思源文件同步结果，不作字段级合并；设置表单未提交时收到外部更新保留输入并提示。实际窗口几何和打开状态维持设备隔离；未提交草稿以独立版本共享。

## 0.1.28 独立列表与 Markdown 即时渲染

### 列表与便签编辑交互调整

当前入口名称统一为“速记列表”（英文 `Note list`），保留 `recentQuickNotes` 命令标识、通信动作和已有数据文件名。列表不再使用页签：右上角齿轮进入设置、左上角返回列表，保留设置草稿及列表搜索/滚动。顶部新建、置顶、设置、最小化、关闭均使用与便签相同尺寸和描边的 SVG；从右侧对齐公共控制按钮。`shortcutBehavior` 增加 `list`，在插件快捷键入口先分派列表，再处理原生窗口及便签数量限制；旧配置和默认值继续沿用。

渲染不再根据选区展开 Markdown。行内格式、图片链接及围栏标记保持隐藏，表格为不可编辑渲染组件，移除图片/表格/链接点击展开源码入口。底栏始终保留源码和工具栏开关，仅成功状态文本可隐藏；源码模式停用全部渲染及图片预览。工具栏默认收起并按宽度收纳到更多菜单，显示和源码状态仅在当前窗口有效，按钮顺序跨设备同步。

格式命令以一次独立撤销事务修改选区，多段按段处理，部分取消格式时保留选区外的原格式。空选区通过独立状态字段跟踪待输入标记，避免空加粗被解释为分隔线；下划线仅识别无属性的配对 `<u>`，不执行 HTML。链接地址输入保存原选区，并在插入时检查正文与可编辑状态。隐藏范围接入 CodeMirror atomicRanges，边界删除移除成对标记，跨边界替换修复剩余标记；源码切回渲染时把落在隐藏标记内部的端点移到可见边界。未支持语法仍保留原文，保存、冲突及草稿协议不变。

以下记录为本版初次接入列表与设置时的实现背景；界面与渲染交互以上述调整为准。

列表内新增“速记 / 设置”页签，顶栏、托盘及插件 `openSetting` 入口统一调用 `show('settings')`，不提前唤醒主窗口。内置设置表单保留全部 14 个配置项并支持中英文；切换页签保留设置草稿及列表搜索/滚动位置，设置正文独立滚动、保存按钮固定在底部。重新载入是显式丢弃未保存输入的操作。打开宿主管理的快捷键设置时先唤醒思源，再最小化列表，避免置顶窗口遮挡。

设置通过列表会话的 `settings`、`preview-settings`、`save-settings` 与 `shortcuts` 动作调用宿主；相关消息校验完整配置字段类型、枚举、有限数值和字符串长度。宿主与降级面板共用交互校验及设置写入队列，仅在确认落盘后更新活动配置、托盘和便签。宿主独立核对可用笔记本与模板解析，预览不创建文档；历史裁剪落盘异常作为“设置已保存”的附加提示返回。子页面通过 requestId 匹配响应，保存失败保留输入，目录改动后忽略旧预览，心跳/列表刷新不覆盖设置表单。原生窗口不可用时保留原来的主界面设置面板。

2026-10-19：最近列表通过 `RecentWindowController` 使用现有 ElectronAdapter 创建单实例沙箱窗口。它拥有独立会话频道，宿主校验会话、窗口及条目 ID，按当前窗口、本机草稿、最近索引顺序解析打开动作。列表合并去重并按更新时间排序，变更通知以 250ms 合并刷新；心跳只更新连接、置顶与主题状态，不重建列表。操作失败提示保留到重试或手动刷新。删除确认期间暂时解除列表置顶，并在成功、取消或失败后恢复。

`recent-window.json` 通过原子替换保存在当前设备草稿目录，与 UUID 便签恢复索引分离；列表不占便签数量、不自动恢复打开。沿用主进程 `attachTrayLifetime` 绑定所属 WebContents，清理目标为列表 BrowserWindow，不依赖主窗口一定触发插件卸载。原生创建失败回到旧恢复弹窗。设置新增 `trayClickAction: 'new' | 'recent'`，默认保留新建；托盘点击动态读取已成功保存的设置，不重新注册快捷键。

CodeMirror 使用内置 GFM 语言，`live-markdown.ts` 通过 StateField 提供装饰和块级表格组件，通过 ViewPlugin 将视口范围同步给状态字段。正文、选区、语法树、只读状态或视口变化时更新相应装饰；段落及表格与选区相交时保留源码。超过 50,000 字符的表格保留源码，避免生成过大 DOM。Markdown 文本始终是唯一正文，切换渲染不生成文档编辑事务，重新打开默认启用。

表格单元格仅以文本创建，HTML 不执行；链接仅选中源码，不发起导航。待办框通过一次独立撤销事务更新标记，并在只读或中文组合输入时拒绝修改。代码块不解析示例语法，既有图片资源校验和上传协议继续使用。未增加运行依赖，也不加载外部渲染脚本。

`scripts/verify-ui.mjs` 使用 Playwright 打开真实构建页面与隔离会话。可设置 `DOCS_PLAYWRIGHT` 为本机包路径、`DOCS_CHROMIUM` 为浏览器路径，再执行 `node scripts/verify-ui.mjs`。结果与截图写入忽略跟踪的 `artifacts/ui/`；不连接内核，也不部署插件。

Windows 托盘继续使用 ICO；Linux 从已有 32px 品牌 PNG 生成 `tray.png`；macOS 由构建脚本绘制透明黑色便签轮廓，生成 `trayTemplate.png`（16px/72dpi）和 `trayTemplate@2x.png`（32px/144dpi）。文件名保持原样供 Electron 识别 Template 与 Retina。生成只使用 Node.js 内置模块，不增加依赖；安装包校验检查尺寸、密度、透明背景和单色像素。

0.1.12 更多菜单支持点击外部、键盘焦点移出、Esc、窗口失焦和执行菜单动作后关闭；关闭时取消重新载入的待确认状态。首次点击重新载入保留菜单供第二次确认，收集快照或插件停用时收起菜单。更多按钮同步 aria-expanded。CodeMirror 启用 drawSelection 绘制光标和选区，光标及原生 caret 使用 --text 主题色；避免仅切换页面 CSS 主题时保留 CodeMirror 默认黑色 caret。
