# 开发与构建

需要 Node.js 20.19 或更新的 Node 20/22 LTS、npm。

```sh
npm ci
npm run typecheck
npm test
npm run build
```

`dist/` 是完整插件目录，`package.zip` 是安装包。构建不自动部署到思源工作空间。`npm run dev` 监听宿主入口；修改独立窗口或品牌资源后运行完整构建。

宿主通过已有的 `@electron/remote` 创建原生窗口和自有托盘。子窗口使用 CodeMirror，关闭 Node 集成，并启用沙箱、上下文隔离和 CSP；通过独立会话频道交换内容和轻量状态。

0.1.8 收集窗口快照时同时关闭 CodeMirror DOM 编辑并设置 `EditorState.readOnly`，阻止撤销和重做更改已确认的快照。`windows.json` 的每条几何记录可附带 `note` 身份索引，不包含正文或基线；兼容旧的纯几何格式。恢复候选合并独立索引、最近记录和本机草稿，草稿优先，正式速记回读内核。最近列表裁剪不影响独立索引。加号直接新建，不读取快捷键行为。

设置的目录预览与实际保存共用目标解析和路径校验。交互保存先校验原始输入，再调用模板解析确认结果，随后保存设置；只有恢复旧配置时才使用默认值回退。预览只调用模板解析，不创建文档；修改输入后忽略旧请求的迟到结果。

0.1.9 打开便签时优先采用独立窗口索引中的几何信息，草稿几何仅作为后备；构造原生窗口参数时只复制几何字段，避免将笔记引用带入草稿的 geometry。恢复循环根据实际打开数量判断上限，失败项不占名额。AutoSaveService 从暂停恢复时，若仍有未保存修订且未冲突、删除或停用，重新安排一次防抖保存；未暂停的服务不重置原有定时器。

同版实机发现 Windows 返回的窗口尺寸大于 BrowserWindow 构造尺寸，直接保存 getBounds 会在每次恢复时累积差值。ElectronAdapter 在加载完成后按每个窗口测得的差值校准持久化宽高，位置仍使用 getBounds，不固定扣除像素；手动缩放反映在后续几何记录中。旧尺寸不强制缩小，之后停止累计变大。参考 [Electron BrowserWindow 窗口尺寸接口](https://www.electronjs.org/docs/latest/api/browser-window/#wingetbounds)。跨显示器 DPI 改变仍需实机验收。

0.1.13 修复关闭空间后托盘残留：宿主会直接 `BrowserWindow.destroy()`，不能保证触发插件卸载或 DOM 退出事件。独立 `tray-lifetime.cjs` 通过宿主已有的 `remote.require` 在主进程执行，绑定所属 WebContents 的 `destroyed`、`render-process-gone` 和已提交的主框架导航 `did-navigate`，直接清理独立托盘，不再回调已销毁的渲染器。停用、初始化失败和页面退出会调用同一清理句柄并移除这些监听；取消关闭、隐藏、最小化、子框架及同文档导航不会清理。生命周期模块加载失败时回滚图标，避免创建无法可靠清理的托盘。

正式文档仅通过内核 API 写入，不直接修改 `.sy` 文件或数据库。本机草稿位于 `%LOCALAPPDATA%/SiYuanQuickNotes/<工作空间路径摘要>/`，采用临时文件、fsync 和原子重命名；不进入云同步。

0.1.15 修复插件更新后的旧便签失联和关闭无效。本机思源 3.8.6 的插件生命周期管理器给 `onunload` 5 秒总期限；原窗口快照收集同样等待 5 秒，且排在降级窗口草稿写入后，容易超过宿主预算。现在 `onunload` 立即启动原生窗口停用，停用时快照收集等待 2.5 秒，整个窗口管理器停用最多等待 4 秒。超时后停止服务与频道，并解除对保留窗口原生关闭的拦截；未确认落盘的正文保留供复制。迟到创建的原生窗口直接销毁，迟到快照不用于关闭窗口。正常手动关闭仍使用原来的 5 秒收集期限。

子页面连续 6 秒未收到会话响应时进入失联状态：正文只读但可选择复制，关闭按钮首先提示复制与未保存内容风险，再次点击调用 `window.close()`；确认 5 秒后失效。收到旧会话的有效响应可恢复编辑并重发未确认正文，停用通知则终止通信且同样保留关闭入口。所有响应仍校验会话与窗口身份，不自动将旧窗口接入新会话。

0.1.5 移除保存模式选项和 `getShorthandSavePath` 调用。插件在 Windows 桌面端初始化；保存目录含模板时调用 `/api/template/renderSprig`，请求为 `{ template: directory }`，使用返回字符串作为目录，再追加每条速记的时间戳与 ID。普通目录直接使用。渲染结果校验绝对逻辑路径、控制字符和路径段；模板错误不创建文档。解析后的目标写入草稿并固定，旧速记已存储的 target/docId 继续使用。旧设置中的 storageMode 被忽略，notebook/directory 保持兼容；原先依赖闪念配置且没有选定笔记本的用户需要在插件设置中选择目标笔记本。

0.1.14 修正模板路径含义：含模板变量时，解析结果直接作为完整文档路径，不再追加时间戳与 ID 子文档。目标文档存在时追加独立速记容器，同路径新建通过原有队列串行处理，不覆盖其他速记或正文。普通目录仍追加每条速记的文档名；已落盘的 target/docId 不重算，旧版子文档继续原位编辑。模板结果为根路径 `/` 时拒绝保存，要求包含文档名。设置预览与保存共用解析结果。

依据：[思源 3.8.6 模板 API](https://github.com/siyuan-note/siyuan/blob/v3.8.6/kernel/api/template.go)、[模板解析实现](https://github.com/siyuan-note/siyuan/blob/v3.8.6/kernel/model/template.go)。

0.1.6 删除通过 `/api/block/deleteBlock` 仅删除速记容器，保留整篇文档。删除前核对容器的块 ID 与 custom-quick-note，前后通过 `/api/sqlite/flushTransaction` 刷新查询索引；响应丢失后查询确认块不存在才清理本机草稿与元数据。依据：[思源块删除 API](https://github.com/siyuan-note/siyuan/blob/v3.8.6/docs/API.zh-CN.md#删除块)。

保存前和写入后核对容器与正文，使用宿主 Lute 规范化 Markdown。内核没有 CAS 条件写入，不保证跨客户端原子修改。移动端 `moveLocalShorthands` 只负责导入已有本机速记，不作为正文入口。

品牌原图位于 `assets/`，集市图标与题头图为根目录 `icon.png`、`preview.png`。托盘构建从 `assets/tray-16.png`、`tray-32.png`、`tray-48.png` 组装 ICO；生成提示见 [品牌素材记录](branding.md)。

接口细节见 [可行性报告](feasibility.md)，验证范围见 [测试记录](testing.md)。

0.1.10 重新载入先通过同一草稿写入队列原子替换恢复快照，再切换内存正文、清理草稿；替换失败保留当前修改，清理失败显示错误且留下新正文。期间有新修订则拒绝载入，后续写入保留最新输入；同修订元数据快照同步更新，避免排队的旧快照覆盖新正文。设置保存使用串行队列，仅在内核确认写入成功后更新活动配置；停用时等待队列，迟到结果不刷新窗口或托盘。最近记录逐条验证笔记引用、目标字段和摘要，损坏项不占记录额度。另存副本通过窗口打开流程同步预留名额，在草稿确认落盘后创建原生窗口；满额时不写副本草稿，写失败则释放名额并保留原窗口。

0.1.11 将“最多同时打开的便签”默认值改为 10，支持 1–50；缺失或非法字段回退为 10，升级保留已保存的合法设置。原生窗口打开、快捷键、另存和自动恢复共用上限判断，计数包含等待创建的原生窗口和降级编辑窗口。降低上限只限制后续打开，不强制关闭已有便签；超出自动恢复名额的草稿继续保留。

0.1.12 更多菜单支持点击外部、键盘焦点移出、Esc、窗口失焦和执行菜单动作后关闭；关闭时取消重新载入的待确认状态。首次点击重新载入保留菜单供第二次确认，收集快照或插件停用时收起菜单。更多按钮同步 aria-expanded。CodeMirror 启用 drawSelection 绘制光标和选区，光标及原生 caret 使用 --text 主题色；避免仅切换页面 CSS 主题时保留 CodeMirror 默认黑色 caret。
