# 悬浮速记 0.1.28 / Quick Notes 0.1.28

2026-10-20 · Windows / macOS / Linux · SiYuan 3.8.6+

## 简体中文

本版将随手记、找回草稿与整理旧便签集中到独立窗口，更新完整中英文使用说明与六组操作配图。

- 新速记默认保存在插件中，无需配置笔记本。首次点击“保存到思源中”后，后续修改自动同步；再次点击该按钮打开原文。
- 默认 Markdown 即时渲染，支持源码切换、图片预览、待办切换，以及带 H1–H6 的格式工具栏；工具栏可拖动排序并同步布局。
- 新增独立速记列表、内置设置与独立置顶；支持搜索、标题和摘要分行显示、列表内删除确认、快捷键及托盘左键打开列表。
- 单击标题旁的铅笔修改便签标题，正文保存为原生提示块，支持 NOTE、TIP、IMPORTANT、WARNING、CAUTION 及深浅色背景。新建与思源保存/打开按钮移至右下角。
- 已保存记录、设置及工具栏布局随工作空间同步；草稿和窗口状态按设备隔离。外机草稿只读查看，复制为本机独立便签后编辑。
- 新增整理提醒、归档和批量清除；归档先保存或核实思源正文，清除未保存内容需明确确认。移除状态同步，思源文档和图片保留，其他设备的未保存修改保留恢复入口。
- 保存正文副本，原文删除时提供恢复、删除便签或取消；空白且尚未保存到思源的新便签关闭后自动清理。
- 中英文说明图均使用本版真实构建与离线演示数据，通过固定提交链接加载，说明图不进入安装包。

升级保留已有设置及内容。旧超级块在下次修改或显式保存时转换为原生提示块，不批量迁移思源文档。设备草稿目录与同步要求见 [使用说明](../../README.md)。

## English

This release brings capture, draft recovery and organization into independent windows, with updated bilingual documentation and six illustrated operation guides per language.

- New notes save to plugin drafts without notebook setup. Save to SiYuan manually once to enable later autosync; the same button then opens the original.
- Markdown live rendering, source toggle, image previews, task toggles, and a reorderable formatting toolbar with Paragraph and H1–H6. Toolbar layout follows workspace sync.
- An independent, pinnable note list with embedded settings, search, separate title/body summaries, inline delete confirmation, and shortcut/tray routing.
- Click the pencil to edit note titles. Notes use native NOTE, TIP, IMPORTANT, WARNING or CAUTION callouts with light/dark palettes. New note and SiYuan actions are at the bottom right.
- Saved references, settings and toolbar layout sync. Drafts and window state remain device-specific. Synced foreign drafts are read-only; copy one to create an independent editable note.
- Organization reminders, archive and batch clear. Archive saves or verifies SiYuan content first; discarding unsaved plugin content requires explicit confirmation. Removal propagates while keeping SiYuan documents/images and foreign unsaved edits recoverable.
- Full body copies support recovery when the original is deleted. Empty new notes that have never been saved to SiYuan are cleared on close.
- Both guides show the real localized build with offline sample content. Images use immutable commit URLs and remain outside the installation package.

Existing settings and content are retained. Legacy superblocks convert on the next edit or explicit save; updating does not migrate SiYuan documents in bulk. See the [user guide](../../README_en_US.md) for draft storage and synchronization requirements.
