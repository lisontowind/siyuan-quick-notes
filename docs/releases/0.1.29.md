# 悬浮速记 0.1.29 / Quick Notes 0.1.29

2026-10-20 · Windows / macOS / Linux · SiYuan 3.8.6+

## 简体中文

- 新增“设置 → 保存与历史 → 默认保存到思源”开关，默认关闭。开启后，当前打开、新建或重新打开的非空便签按自动保存间隔写入思源，默认停笔 800 毫秒保存；只有标题的便签也支持保存，空白便签不创建文档。
- 保存失败时保留本机草稿，可继续编辑或重试。关闭开关后，尚未保存到思源的便签恢复使用插件草稿，已保存便签继续自动保存后续修改。关闭状态的旧草稿在重新打开后才自动保存。
- 正文保存到思源后，通过思源数据同步传到其他设备；各设备需连接同一个同步空间并完成同步。本开关负责自动写入思源，云端同步由思源负责。
- 列表关闭后隐藏并复用窗口，保留搜索、滚动位置和未提交的设置。首次打开、重新唤起及手动刷新立即加载内容，慢速整理统计不再阻挡列表显示；隐藏时暂停安排列表刷新。
- 设置保存时原位更新确认值，保留控件、预览、焦点、文本选区和滚动位置；保存期间保持界面布局稳定，并防止重复提交。
- “其他设备草稿”改为列表窗口内的整页视图，支持只读预览、来源切换、刷新和复制到本设备。通过公共返回按钮或 Escape 回到列表，离开页面后忽略迟到的结果。

升级保留已有设置和内容。新开关默认关闭，升级后保持原有草稿优先行为。使用自动保存前，请先确认目标笔记本和保存目录。

## English

- Added **Settings → Saving and history → Save to SiYuan by default**, off by default. Nonempty notes that are open, newly created or reopened save after the configured delay, 800 ms by default. Title-only notes are supported; blank notes create no document.
- Failed saves retain local drafts for editing or retry. Turning the switch off keeps unsaved notes in plugin drafts; notes already saved to SiYuan continue autosaving. Closed drafts save when reopened.
- Saved content reaches other devices through SiYuan data sync. Configure the same sync space on each device and wait for synchronization to finish. This switch automates writing to SiYuan; SiYuan handles cloud sync.
- Closing the list hides and reuses its window, retaining search, scroll position and unsubmitted settings. Opening, reopening and manual refresh load content immediately, independently of slow organization statistics. Hidden windows stop scheduling list refreshes.
- Settings saves update confirmed values in place, preserving controls, previews, focus, text selection and scroll position. The form remains visually stable and prevents duplicate submissions.
- Other devices’ drafts now use a full-page view inside the list window, with read-only preview, source selection, refresh and copy to this device. Back or Escape returns to the list, and late results are ignored after leaving the page.

Existing settings and content are retained. The new switch defaults to off, preserving plugin drafts on upgrade. Select a target notebook and save directory before enabling automatic saving.

Type checking, 390 tests across 23 files, production build and package verification pass. Headless Edge UI regression checks cover switch defaults and persistence, stable settings saves, list loading and full-page draft navigation, with Chinese/English, light/dark and narrow layouts.

Checks use isolated pages and simulated hosts. Real multi-device SiYuan sync and native Windows/macOS/Linux behavior were not verified on hardware in this release cycle. See the [testing record](../testing.md).
