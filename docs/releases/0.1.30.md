# 悬浮速记 0.1.30 / Quick Notes 0.1.30

2026-11-04 · Windows / macOS / Linux · SiYuan 3.8.6+

## 简体中文

- 列表的关闭、最小化、置顶和整理取消独立处理，设置预览、保存或内核请求较慢时仍可操作。窗口销毁后，旧窗口的迟到响应和排队请求不会影响替代窗口。
- 批量归档和清除改为定向读取目标草稿、正文副本、共享索引及删除标记，减少无关正文读取。执行前继续核对记录签名，保留处理中发生变化的草稿及损坏文件。
- 列表与整理统计复用同轮尚未完成的索引和草稿读取；后续刷新重新读取磁盘。后台统计最多每 2 秒刷新一次，隐藏列表时取消待执行刷新，显式打开整理页仍读取最新数据。
- 统一草稿、正文副本、窗口状态、整理记录和共享数据的原子写入。写入、同步、关闭文件句柄或重命名失败时清理本次临时文件，保留已确认文件。
- 固定 Playwright 测试依赖，新增 `npm run test:ui`，并为 Linux GitHub Actions 增加隔离页面检查和结果上传。保留测试范围限制及 Markdown 语法树测试稳定性修正。

升级保留已有设置和便签内容，无需迁移存储格式。

## English

- List close, minimize, pin and organization cancellation remain responsive during slow settings previews, saves or kernel requests. Late responses and queued commands from destroyed windows cannot affect their replacements.
- Batch archive and clear revalidate target drafts, saved copies, shared metadata and deletion markers without repeatedly reading unrelated bodies. Signature checks continue to protect changed drafts and damaged files.
- The list and organization statistics share reads that are already in flight. Later refreshes read disk again. Background statistics refresh at most once every two seconds, hidden lists cancel deferred refreshes, and opening organization explicitly still loads current data.
- Drafts, saved copies, window state, maintenance records and shared data use a common atomic JSON writer. Failed writes, syncs, handle closes or renames remove their temporary file while retaining the confirmed file.
- Pinned Playwright dependencies and added `npm run test:ui`, isolated page checks and result uploads in Linux GitHub Actions. Included project-only test discovery and the Markdown syntax-tree test stability fix.

Existing settings and note content are retained; no storage-format migration is required.

## 验证 / Validation

类型检查、24 个测试文件的 402 项测试、生产构建与安装包完整性校验，以及 Chromium 无头隔离页面回归通过。测试覆盖慢操作中的窗口控制、旧窗口隔离、统计节流、同轮读取复用、正文变化保护与四阶段写盘故障。

Type checking, 402 tests across 24 files, production build, package verification and headless Chromium checks on isolated pages pass. Tests cover responsive controls, replacement-window isolation, throttled statistics, shared in-flight reads, changed-content protection and four write-failure stages.

隔离内存模拟中，清除 80 条草稿从累计遍历 12,960 个草稿条目降为 320 次定向草稿读取。此结果不代表真实磁盘耗时，共享索引仍需枚举文件名以发现同步的新设备版本。

In an isolated in-memory simulation, clearing 80 drafts changed from enumerating 12,960 draft records to 320 targeted draft reads. This is not a real-disk timing measurement; shared metadata still enumerates filenames to discover newly synced device versions.

测试使用隔离页面和模拟宿主，未连接真实思源工作空间；本轮未验收真实多机同步或 Windows/macOS/Linux 原生窗口行为。详见 [测试记录](../testing.md)。

Checks use isolated pages and simulated hosts without connecting to a real SiYuan workspace. Real multi-device sync and native Windows/macOS/Linux behavior were not verified in this release cycle. See the [testing record](../testing.md).
