# 悬浮速记 0.1.33 / Quick Notes 0.1.33

2026-11-18 · Windows / macOS / Linux · SiYuan 3.8.6+

## 简体中文

- 空白便签的底栏提示缩短为“自动保存到插件”，英文同步精简，在 300px、320px 宽度下保持单行。
- 便签和列表的脚本、样式地址增加文件内容指纹，避免升级后继续复用旧缓存；安装包校验检查指纹与实际资源一致。
- 从已有透明原图重新导出 16、32、48 像素托盘素材，清除圆角外残留的绿色背景，恢复 Windows 和 Linux 托盘图标圆角。
- Windows ICO 包含三个修正后的尺寸；Linux PNG 使用修正后的 32 像素素材。macOS 单色托盘模板沿用现有设计。

更新后请重启一次思源，让已打开的旧窗口和托盘重新加载。已有设置与便签内容保留，无需迁移存储格式。

## English

- Shortened the empty-note footer hint to “Autosaves in plugin”, with a shorter Chinese hint as well. Both fit on one line at 300px and 320px widths.
- Note and list script/style URLs include content fingerprints to avoid stale cached resources after upgrades. Package verification checks that fingerprints match the bundled files.
- Regenerated the 16px, 32px and 48px tray assets from the existing transparent source, removing green pixels outside the rounded tile for Windows and Linux.
- Windows ICO includes all three corrected sizes; Linux PNG uses the corrected 32px asset. The macOS monochrome tray template keeps its existing design.

Restart SiYuan once after updating to reload existing windows and the tray. Existing settings and note content are retained; no storage-format migration is required.

## 验证 / Validation

类型检查、24 个测试文件的 402 项测试、生产构建及安装包校验通过。隔离页面与模拟宿主的界面回归通过；缓存升级模拟验证新资源地址加载短提示。Windows 原生 ICO 解码确认 16、32、48 像素帧四角 alpha 均为 0。

Type checking, 402 tests across 24 files, production build and package verification pass. Isolated page checks with simulated hosts pass; a cached-upgrade simulation confirms that new asset URLs load the short hint. Native Windows ICO decoding confirms transparent corners in all three sizes.

界面验证使用隔离页面和模拟宿主，未连接真实思源工作空间。本轮未验收真实多机同步及 macOS/Linux 原生托盘显示。

UI checks use isolated pages and simulated hosts without connecting to a real SiYuan workspace. Real multi-device sync and native macOS/Linux tray rendering were not verified in this release cycle.
